# Vite & Gourmand

Application web — ECF Développeur Web et Web Mobile | Studi

## 📋 Présentation

**Vite & Gourmand** est une application web réalisée dans le cadre de l'ECF Développeur Web et Web Mobile de la formation Studi.

L'application a été développée pour le compte de l'entreprise fictive **Vite & Gourmand**, un traiteur basé à Bordeaux.

### Objectifs du projet

* Augmenter la visibilité de l'entreprise sur le web.
* Présenter les différents menus proposés à un public plus large.
* Permettre aux utilisateurs de passer commande directement depuis l'application.

La fonctionnalité principale du projet est la possibilité de **commander des menus en ligne**, offrant ainsi une expérience plus complète aux clients de l'entreprise.
